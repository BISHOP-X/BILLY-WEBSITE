# Billy Website

Promotional landing page for the Billy mobile application.

This repository is intentionally independent from the Billy React Native application and its Supabase backend. The store buttons currently show an honest pre-launch notice; replace them with the official App Store and Google Play URLs when the listings are live.

## Local preview

Open `index.html` directly, or serve this directory with any static HTTP server.

## Deployment

The site is configured for Vercel as a static project.
